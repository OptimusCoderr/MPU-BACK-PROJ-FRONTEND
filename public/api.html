📡 Readings
Raw MPU6050 pitch/roll data points. The ESP32 POSTs here every 100ms.
POST/api/readingsSubmit sensor reading (single or batch)▾
Fields
Example
Try It
FieldTypeRequiredDescription
pitchnumberYesForward/back tilt in degrees. >15° triggers slouch.
rollnumberYesSide-to-side tilt in degrees.
readingsarrayNoArray of {pitch,roll} for batch insert. Use instead of single fields.
Single
{ "pitch": 12.4, "roll": -3.1 }
Batch
{ "readings": [ { "pitch": 5.2, "roll": 1.0 }, { "pitch": 18.7, "roll": 0.5 } ] }
Body (JSON)

⏱ Sessions
A session is one posture monitoring run. Start → timer counts down in browser → stop saves to MongoDB.
POST/api/sessions/startStart a new session▾
Fields
Try It
FieldTypeRequiredDescription
durationnumberNoSeconds (10–3600). Default: 2700 (45 min)
patientIdstringNoPatient ID. Default: User1
notesstringNoSession notes
Body
POST/api/sessions/stopStop active session with final stats▾
Fields
Try It
FieldTypeDescription
elapsednumberTotal seconds elapsed
goodSecondsnumberSeconds with good posture
badSecondsnumberSeconds slouching
slouchCountnumberNumber of slouch events
statusstringCompleted or Manual Stop
