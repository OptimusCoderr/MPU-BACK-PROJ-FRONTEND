🔍 Health & Status
Check whether the server, database, and sensor poller are all running correctly.
GET /api/status Full server health snapshot ▾
Description
Example
Try It

Returns a full snapshot of the server including DB connection state, active session info, poller statistics, latest sensor readings, and uptime.

200 OK 500 Server Error
Response 200
{
  "ok": true,
  "env": "development",
  "uptime": 142,
  "db": { "connected": true, "state": "connected" },
  "poller": { "intervalMs": 100, "totalPolls": 850, "totalErrors": 0 },
  "session": { "active": false, "id": null },
  "sensor": { "currentPitch": 0, "threshold": 15 },
  "mode": "db"
}
📡 Readings
Raw MPU6050 pitch and roll data points. The ESP32 device POSTs here. The server polls these every 100ms and broadcasts live to the browser.
POST /api/readings Submit a single sensor reading ▾
Fields
Example
Try It
FieldTypeRequiredDescription
pitchnumberYesForward/back tilt in degrees. Values >15° trigger slouch detection.
rollnumberYesSide-to-side tilt in degrees.
201 Created 400 Missing fields
Request Body
{ "pitch": 12.4, "roll": -3.1 }
Response 201
{ "ok": true, "id": "66a1b2c3d4e5f6a7b8c9d0e1" }
Request Body (JSON)
POST /api/readings batch Submit multiple readings at once ▾
Description
Example
Try It

Send an array of readings in a single request. Useful for buffered uploads from the device when WiFi was temporarily unavailable. Invalid rows are skipped silently.

201 Created 400 No valid readings
Request Body
{
  "readings": [
    { "pitch": 5.2,  "roll": 1.0 },
    { "pitch": 18.7, "roll": 0.5 },
    { "pitch": 3.0,  "roll": 0.1, "recordedAt": "2026-03-15T10:00:00.000Z" }
  ]
}
Response 201
{ "ok": true, "count": 3 }
Request Body (JSON)

⏱ Sessions
A session is one posture monitoring run. Start it, let the timer count down, and it saves a full summary to MongoDB when complete.
POST /api/sessions/start Start a new session ▾
Fields
Durations
Try It
FieldTypeRequiredDescription
durationnumberNoSession length in seconds. Range 10–3600. Default: 2700
patientIdstringNoPatient ID string. Default: User1
notesstringNoOptional clinical notes
201 Created 409 Already active
Duration Reference
// seconds → label
10    → 10 seconds (quick test)
30    → 30 seconds
60    → 1 minute
300   → 5 minutes
600   → 10 minutes
900   → 15 minutes
1800  → 30 minutes
2700  → 45 minutes (default)
3600  → 60 minutes
Request Body
